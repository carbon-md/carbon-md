# Concepts

**Mesurer → gouverner → contribuer → prouver.**

- **Mesurer** : tokens aux goulots, fourchettes CO₂e, cache-read exclu.
- **Gouverner** : fichier `carbon.md` humain.
- **Contribuer** : removal vérifié, confirm-first.
- **Prouver** : ledger + badge, jamais « carbon neutral ».

Voir [Catalogue modèles](/fr/models/) et [Méthodologie](/fr/methodology/).
