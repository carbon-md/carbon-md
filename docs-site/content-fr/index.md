# Documentation carbon.md

**Un standard ouvert pour des agents IA gouvernés carbone.** Un fichier `carbon.md` dans votre dépôt déclare la politique carbone de vos agents.

Les humains fixent la politique. Les agents l’exécutent. Tout est prouvable.

```bash
npx carbon-md init
```

> **Nouveau ici ?** [Démarrage rapide](/fr/quickstart/) — puis [Concepts](/fr/concepts/).

## Ce que c’est

1. **Mesurer** — tokens → CO₂e avec fourchettes.
2. **Gouverner** — politique humaine (cible, budget, seuil).
3. **Contribuer** — carbon removal vérifié, confirm-first.
4. **Prouver** — ledger public + badge. Pas de claim « neutral ».
