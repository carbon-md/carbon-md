# Démarrage rapide

Environ cinq minutes. Pas de compte, pas de clé API.

## 1. Init
```bash
npx carbon-md init
```

## 2. Usage
```bash
npx carbon-md sync claude-code
npx carbon-md sync hermes
npx carbon-md ingest usage.jsonl
```

## 3. Status
```bash
npx carbon-md status
```

## 4–5. Contribuer & prouver
```bash
npx carbon-md contribute
npx carbon-md export
```

Boucle : **mesurer → gouverner → contribuer → prouver**.
